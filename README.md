# Splitwise Lite

A lite mobile expense-sharing application built with Expo React Native and an Express/MongoDB API.
This project is for education and practice purposes only.

## Server Features

- User registration and login
- Server-side JWT session tracking and logout revocation
- Group creation
- Creator-controlled member invitations
- Equal expense splitting
- Group balance calculation
- Debt simplification
- Settlement requests
- Settlement confirmation or rejection
- Expense deletion by the original payer
